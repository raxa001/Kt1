# Конфликт в Git

Конфликт возник в файле README.md при слиянии веток conflict-1 и conflict-2.
Обе ветки меняли одну и ту же строку — заголовок проекта.

- conflict-1: "# Библиотека учебная"
- conflict-2: "# Электронная библиотека"

Исправлено вручную: оставлена строка "# Электронная библиотека",
маркеры конфликта (<<<<<<<, =======, >>>>>>>) удалены.
Сделан отдельный коммит "Исправил конфликт в README".
